# Domain Glossary: AI Japanese Teacher

## Core Concepts

### Daily Lesson
A single study session consisting of a thematic **Lesson Topic**, a curated **Target Vocabulary** set (3–5 items), a contextual **Generated Passage** (dialogue or story), and synchronized **Audio**.

### Target Vocabulary
A curated set of Japanese words/kanji selected for a session. Words are chosen to be semantically and topically cohesive (e.g., "ordering at a café" or "train travel"), graded to the learner's chosen proficiency level (JLPT N5 through N1). Each word includes Kanji, Furigana, Romaji, English definition, part of speech, and 3 audio-supported context examples.

### Generated Passage
A natural, level-appropriate Japanese text (dialogue roleplay with distinct speaker characters) generated by the AI language model. It embeds all **Target Vocabulary** in natural context, with Furigana (ruby text) support and sentence-by-sentence segmentation.

### Furigana Annotation
Phonetic reading aids (Hiragana) rendered directly above Kanji characters using tokenized structures (`surface`, `reading`, `isTarget`).

### Audio Provider
An interchangeable speech synthesis adapter responsible for rendering spoken Japanese from text. Supports speed modification (0.75x–1.25x), sentence looping, and pluggable backends (Native Device Speech API via `expo-speech`, Google Cloud Neural TTS, ElevenLabs).

### Learned Word Bank
A persistent, cumulative dictionary of all vocabulary words and example sentences encountered across daily lessons. Words in the Word Bank remain permanently stored even if older lesson dialogues rotate out.

### Lesson Retention Policy (FIFO + Starred Pinning)
Auto-saved un-starred lesson dialogues are stored in local storage with a FIFO capacity limit (e.g., 25 recent lessons) to prevent storage bloat. Lessons marked as **⭐ Starred / Favorite** bypass the FIFO eviction queue and are stored permanently.

### Core Navigation Surfaces
- 🏠 **Learn**: Home hub for level selection, daily topic suggestions, custom topic prompting, and active 2-screen lesson study.
- 📖 **History**: Chronological log of past lessons with search, JLPT filters, and Starred filter.
- 🗂️ **Word Bank**: Cumulative dictionary of all learned words with search, Furigana, and individual audio playback.
- ⚙️ **Settings**: Gemini API key management, Japanese voice selection, default speed preference, default JLPT level, and local data management.
